# Testing Purpose

This repository is a Playwright-based automated testing suite designed for web applications. It includes a collection of positive and negative test cases to ensure application reliability.

## Purpose

The primary goal of this project is to provide a structured framework for end-to-end (E2E) testing, leveraging Playwright's powerful features for browser automation. It serves as a testing ground for various scenarios, including login flows and UI interactions.

## Features

- **Automated E2E Tests**: Comprehensive tests for web application workflows.
- **Positive & Negative Scenarios**: Validates both expected behavior and error handling.
- **CI/CD Integration**: Integrated with GitHub Actions for automated test execution on every push.

## Getting Started

### Installation

```bash
npm install
```

### Running Tests

- Run all tests: `npm test`
- Run tests in UI mode: `npm run test:ui`
- Run tests in headed mode: `npm run test:headed`
